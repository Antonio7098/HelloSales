# Central Pulse

Central Pulse is the observability dashboard frontend for HelloSales.

## Purpose

This frontend provides the operator-facing dashboard for:
- Monitoring agent runs, worker executions, and system health
- Viewing metrics,traces, and logs from the self-hosted observability stack
- Drill-downs into operational events and diagnostics

## Tech Stack

- React (same as main frontend)
- Vite for dev server
- API proxy to backend

## Status

This directory is currently empty and awaiting development.
