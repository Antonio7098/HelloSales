# Review Phase

This directory contains the protocols and templates for the review phase.

## Purpose

The review phase verifies conformance to the reasoning document and governing contracts, and produces a structured report.

## Key Characteristics

Review should:
- perform a high-signal code review in order
- verify conformance against the requirements mapped in reasoning
- record findings with severity and evidence
- produce a report that leaves a future reader able to understand what was planned, delivered, and whether it conforms

## Files

- `review-protocol.md` - Protocol for the main review
- `contract-review-protocol.md` - Protocol for specialized contract-area review
- `report-template.md` - Template for the sprint report

## When To Use

The review phase follows the execution phase.
It produces a report that can be used for sign-off, retrospective assessment, and next-sprint planning.
