# Execution Phase

This directory contains the protocol and template for the execution phase.

## Purpose

The execution phase implements the work while adhering to the reasoning document and mapped requirements.

## Key Characteristics

Execution should:
- follow the mapped requirements and justified decisions from reasoning
- preserve constraints and invariants identified in reasoning
- collect the evidence that review will need later
- update the reasoning document when scope discoveries or deviations occur

## Files

- `execution-protocol.md` - Protocol for sprint execution
- `tracker-template.md` - Template for the sprint tracker

## When To Use

The execution phase follows the reasoning phase.
It produces code, tests, and review-ready evidence.
