# Feature Process

This directory contains the protocol and template for product-focused feature documents.

## Purpose

The feature process creates non-technical product requirements in `ops/features/`.

Feature documents define:
- who the feature is for
- why it matters
- what user outcome it should create
- what product behavior is expected
- what is in and out of scope
- how success will be recognized
- which sprints are connected to the feature

## Files

- `feature-protocol.md` - Protocol for creating and maintaining feature documents
- `feature-template.md` - Template for a feature document

## When To Use

Use this process before sprint planning when the product need is not yet captured, or during sprint work when product requirements need to be clarified without turning the feature document into a technical design.
